# Calendário

Visões mensal, semanal e diária dos mesmos agendamentos da tela de Agendamentos (store compartilhado em `../agendamentos/store`).
Entrada: `import { CalendarioPage } from './features/calendario'`. Documentação completa de integração, contrato dos componentes existentes e dados em memória: ver `../agendamentos/README.md`.

- Clique em um evento: detalhes (editar, confirmar, cancelar, reabrir).
- Clique em um horário livre nas visões semanal/diária: abre o formulário já com data e hora.
- Legenda por status funciona como filtro; filtro por responsável.
