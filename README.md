# Agenda de Serviços

Sistema web para gerenciamento de serviços, profissionais e agendamentos.

## Objetivo

Desenvolver uma aplicação que facilite o cadastro e a organização de serviços, profissionais e horários de atendimento, evitando conflitos nos agendamentos.

## Funcionalidades

- Cadastro de serviços.
- Cadastro de profissionais.
- Gerenciamento de agendamentos.
- Organização dos horários de atendimento.
- Prevenção de conflitos de horários.
